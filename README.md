# Day 39 – Confusion Matrix

## Project: Titanic Survival Prediction

### Objective
To evaluate a Machine Learning classification model using a Confusion Matrix.

### Dataset
Titanic Dataset.

### Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

### Algorithm
Logistic Regression

### Features
- Passenger Class
- Gender
- Age
- Fare

### Target
Survived (0 = Not Survived, 1 = Survived)

### Evaluation
- Confusion Matrix
- Accuracy Score
- Classification Report
- Heatmap Visualization

### Conclusion
Successfully implemented a Confusion Matrix to evaluate Titanic survival predictions and understand True Positive, True Negative, False Positive and False Negative values.
